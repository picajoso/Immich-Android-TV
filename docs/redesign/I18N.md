# Languages

The app follows the language selected in Android TV. Supported: English (default) and Spanish.

- UI text is written in English in the code and looked up with `Tr.t("English text")`
  (`shared/util/Tr.kt`): it finds the string resource `t_<normalised text>`; without a translation
  the English original is shown. Counts use `Tr.photos(n)` / `Tr.people(n)` (`%d` patterns).
- The strings live in `app/src/main/res/values/strings_tr.xml` (English) and
  `values-es/strings_tr.xml` (Spanish); they are generated from the `Tr.t(...)` calls and the
  preference definitions by `docs/redesign/i18n-gen.py`, with the translations in a dictionary
  `es.py` next to it (EN text -> ES text).
- Option lists of the settings screens: `res/values/arrays.xml` + `res/values-es/arrays.xml`.
- Viewer (mediaslider module): `res/values*/strings_viewer.xml`.
- New language: add its dictionary to the generator and a `values-xx/` copy of the three files.
